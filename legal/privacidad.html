Aviso de privacidad

ClickOnMe trata los datos que proporcionas para crear, publicar y administrar tu tarjeta digital, autenticar tu cuenta, procesar pagos y enviarte avisos relacionados con el servicio.

Datos que utilizamos

  • Correo electrónico y datos de autenticación administrados por nuestro proveedor de identidad.
  • Nombre, actividad, fotografía, enlaces, teléfonos y contenido que decidas publicar.
  • Estado y referencia de pagos. ClickOnMe no almacena números completos de tarjeta ni códigos de seguridad.
  • Registros técnicos necesarios para seguridad, diagnóstico y prevención de abuso.

Proveedores

Usamos servicios tecnológicos como Supabase para base de datos y autenticación, Mercado Pago para cobros, Resend para correos transaccionales, GitHub Pages para publicación y Hostinger para administración del dominio. Cada proveedor trata información conforme a sus propios avisos y a las instrucciones necesarias para prestar el servicio.

Finalidades y conservación

Los datos se usan para operar la plataforma, atender soporte, confirmar pagos, administrar vigencias y cumplir obligaciones aplicables. Conservamos la información mientras la cuenta esté activa o durante el plazo razonablemente necesario para seguridad, soporte y obligaciones legales.

Tus decisiones

Puedes solicitar acceso, corrección o eliminación de tus datos y revocar comunicaciones no esenciales escribiendo a soporte@clickonme.pro. Las tarjetas suspendidas dejan de mostrarse públicamente, pero pueden conservarse para permitir su renovación hasta que se solicite su eliminación.

Nunca envíes contraseñas, claves API ni datos completos de tarjeta por correo o chat.
